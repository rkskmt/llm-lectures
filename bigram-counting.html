質問

地名のよみで、「ょ」の次に来る文字は何が多い？ 「きょうと」「ちょうし」…… 予想してから、数えて確かめる。

  • 今日のモデルの作戦はこれだけ：直前の1文字だけ見て、次の1文字を当てる

バイグラム — 隣り合う2文字

  • 隣り合う2文字の組をバイグラム（bigram）と呼ぶ
  • 「しぶや」のバイグラム：「し→ぶ」「ぶ→や」
  • データ全体でこの組を数えるだけ。学習も勾配もまだ使わない

ノート

「次の1文字を当てる分類器」の最弱バージョン。弱いが、動くものを最初に作るのはシステム作りの鉄則。

名前の始まりと終わりに印を打つ

  • 「どの文字で始まりやすいか」「どこで終わるか」も当てたい
  • そこで名前の前後に境界の印「・」を付けてから数える

  • 「・→し」＝「し」で始まった、「や→・」＝「や」で終わった、と読む
  • 語彙は74＋1で75文字になる

全部数える

import numpy as np
import pandas as pd

names = pd.read_csv("data/chimei.csv")["yomi"].tolist()
chars = ["・"] + sorted(set("".join(names)))   # 境界を0番にする
stoi = {c: i for i, c in enumerate(chars)}

N = np.zeros((75, 75), dtype=int)
for name in names:
    seq = "・" + name + "・"
    for a, b in zip(seq, seq[1:]):     # 隣り合う2文字を順に取る
        N[stoi[a], stoi[b]] += 1

print("組の総数:", N.sum())
print("「ょ→う」の回数:", N[stoi["ょ"], stoi["う"]])

「ょ→う」の回数: 509

質問

「・」の行のトップ5＝名前の最初に来やすい文字。何だと思う？ 「・」の列のトップ5＝名前の最後の文字。こっちはかなり偏るはず……

import numpy as np
import pandas as pd

names = pd.read_csv("data/chimei.csv")["yomi"].tolist()
chars = ["・"] + sorted(set("".join(names)))
stoi = {c: i for i, c in enumerate(chars)}
N = np.zeros((75, 75), dtype=int)
for name in names:
    seq = "・" + name + "・"
    for a, b in zip(seq, seq[1:]):
        N[stoi[a], stoi[b]] += 1

first = N[0].argsort()[::-1][:5]        # ・の行：最初の文字
last = N[:, 0].argsort()[::-1][:5]      # ・の列：最後の文字
print("最初:", [(chars[i], N[0, i]) for i in first])
print("最後:", [(chars[i], N[i, 0]) for i in last])
最初: [('か', np.int64(135)), ('お', np.int64(123)), ('い', np.int64(106)), ('み', np.int64(102)), ('し', np.int64(98))]
最後: [('し', np.int64(792)), ('う', np.int64(466)), ('ち', np.int64(277)), ('ら', np.int64(161)), ('ん', np.int64(28))]

  • 誰も教えていないのに、数えただけで「地名の文法」が浮かび上がる

回数を確率に直す

  • 行の合計で割れば、その文字の次に来る文字の確率分布になる

  • 前コースの分類器の出力（10クラスの確率）と同じ形。クラスが75個になっただけ
import numpy as np
import pandas as pd

names = pd.read_csv("data/chimei.csv")["yomi"].tolist()
chars = ["・"] + sorted(set("".join(names)))
stoi = {c: i for i, c in enumerate(chars)}
N = np.zeros((75, 75), dtype=int)
for name in names:
    seq = "・" + name + "・"
    for a, b in zip(seq, seq[1:]):
        N[stoi[a], stoi[b]] += 1

P = N / N.sum(axis=1, keepdims=True)   # 各行を合計1に
print("P(う|ょ) =", P[stoi["ょ"], stoi["う"]].round(4))
print("P(・|し) =", P[stoi["し"], stoi["・"]].round(4))   # 「し」で終わる確率
P(う|ょ) = 0.9903
P(・|し) = 0.7097
  • 「ょ」の次は99%「う」。「し」まで来たら71%でそこで終わり

確率で1文字選ぶ

  • 分布から確率に比例して1文字引く。イメージは区間の広さが確率に比例したルーレット
  • 「か」のルーレットは わ・し・み…と割れている。「ょ」はほぼ「う」一色 — 行ごとに違うルーレットを回す
  • これをやってくれるのが np.random.choice(..., p=確率)
import numpy as np
import pandas as pd

names = pd.read_csv("data/chimei.csv")["yomi"].tolist()
chars = ["・"] + sorted(set("".join(names)))
stoi = {c: i for i, c in enumerate(chars)}
N = np.zeros((75, 75), dtype=int)
for name in names:
    seq = "・" + name + "・"
    for a, b in zip(seq, seq[1:]):
        N[stoi[a], stoi[b]] += 1
P = N / N.sum(axis=1, keepdims=True)

rng = np.random.default_rng(0)
i = stoi["ょ"]
for _ in range(5):
    print(chars[rng.choice(75, p=P[i])], end=" ")   # 「ょ」の次を5回引く
う う う う う
  • ほぼ「う」、たまに別の字 — サイコロの目が確率表どおりに偏っている

生成 — 表とサイコロだけで名前を作る

  • 「・」から始めて、出た文字を次の入力にして繰り返す。「・」が出たら終わり

import numpy as np
import pandas as pd

names = pd.read_csv("data/chimei.csv")["yomi"].tolist()
chars = ["・"] + sorted(set("".join(names)))
stoi = {c: i for i, c in enumerate(chars)}
N = np.zeros((75, 75), dtype=int)
for name in names:
    seq = "・" + name + "・"
    for a, b in zip(seq, seq[1:]):
        N[stoi[a], stoi[b]] += 1
P = N / N.sum(axis=1, keepdims=True)

rng = np.random.default_rng(0)
for _ in range(10):
    i, s = 0, ""                        # 0 = 「・」からスタート
    while True:
        i = rng.choice(75, p=P[i])
        if i == 0:
            break                       # 「・」が出たら名前の完成
        s += chars[i]
    print(s)

出来ばえ品評会

  • 「きたやまちょう」「なごうし」 — 実在しないのに、実在しそう

ヒント

出力を毎回変えたいときは default_rng(0) の数字（乱数のシード（random seed））を変える。 同じシードなら同じ出力 — 実験の再現に必須の道具。

変えること 何が起きるか
default_rng(0) → default_rng(7) など 別の名前セットが出る（同じ数字なら毎回同じ）
i, s = 0, "" → i, s = stoi["ふ"], "ふ" 「ふ」で始まる名前だけ作れる

ここで観察

  • argmax 版は毎回同じ1つの名前に行き着く（何が出るかはお楽しみ）。確率で「揺らす」ことが多様さの源
  • 書き出しを変えると、表のその行から旅が始まる — 生成は行から行への乗り継ぎ

まとめ

  • 数えるだけの言語モデル：バイグラム回数表 → 行ごとに確率化 → サイコロで次々引く
  • 境界トークン「・」が「始まりやすさ」「終わりやすさ」まで面倒を見る
  • 一歩一歩は正しいのに全体は迷子 — 記憶が1文字しかないのが弱点
  • 出力は確率的：シードで再現をコントロールする

import numpy as np
import pandas as pd

names = pd.read_csv("data/chimei.csv")["yomi"].tolist()
chars = ["・"] + sorted(set("".join(names)))
stoi = {c: i for i, c in enumerate(chars)}
N = np.zeros((75, 75))
for name in names:
    seq = "・" + name + "・"
    for a, b in zip(seq, seq[1:]):
        N[stoi[a], stoi[b]] += 1
P = N / N.sum(axis=1, keepdims=True)

def score(s):
    seq = "・" + s + "・"
    return np.mean([-np.log(P[stoi[a], stoi[b]]) for a, b in zip(seq, seq[1:])])

print(f"とうきょう: {score('とうきょう'):.3f}")
print(f"ひがわむら: {score('ひがわむら'):.3f}")   # 本編の生成名から1つ

ranked = sorted(set(names), key=score)
print("最も地名らしい:")
for s in ranked[:3]:
    print(f"  {score(s):.2f}  {s}")
print("最も地名らしくない:")
for s in ranked[-5:][::-1]:
    print(f"  {score(s):.2f}  {s}")
