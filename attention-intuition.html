道具はもう持っている：重み付き平均

  • 文字は埋め込みでベクトルになっている（ことばの地図の回）
  • 複数のベクトルを「混ぜる」自然な方法＝重み付き平均（weighted average）

\[ \text{混ぜた結果} = 0.5 \cdot \vec{\vphantom{b}v}_1 + 0.25 \cdot \vec{\vphantom{b}v}_2 + 0.25 \cdot \vec{\vphantom{b}v}_3 \]

  • 重みは合計1の割合。大事な文字に大きな重みを置けば「そこを強く見た」ことになる
  • 問題はただ1つ：その重みを誰がどう決めるか

内積 — 「似ている度」を1つの数に

  • 2本のベクトルの内積（dot product）＝ 成分どうしを掛けて、足すだけ

\[ (1, 1) \cdot (2, 2) = 1 \times 2 + 1 \times 2 = 4 \]

  • 向きが揃うほど大きくなる — 「似ている度」を1つの数で測れる物差し
  • ことばの地図の回の「近い文字＝似た使われ方」と同じ発想の親戚。今日はこの物差しで「関連の深さ」を測る

3ステップの表計算

  • 各文字に2種類のベクトルを持たせる：
    • 持ってる情報 \(\vec{\vphantom{b}v}\)：混ぜられる中身
    • 名札 \(\vec{\vphantom{b}k}\)：「私はこういう情報を持っています」の看板
  • いま予測しようとしている場所は「探しもの」\(\vec{\vphantom{b}q}\) を1本持つ
  • 関連度 ＝ 名札と探しものの内積 — さっきの「似ている度」の物差しをそのまま使う

手計算1往復 — 「名前はまだ」で

ミニ文「名前／は／まだ」の3トークン。「まだ」の場所から過去を見る。数値は電卓なしで埋められるおもちゃサイズにしてある。

トークン 名札 \(\vec{\vphantom{b}k}\) 持ってる情報 \(\vec{\vphantom{b}v}\)
「名前」 \((1, 1)\) \((1, 0)\)
「は」 \((1, 0)\) \((0, 1)\)
「まだ」 \((0, 1)\) \((1, 1)\)

「まだ」の探しもの：\(\vec{\vphantom{b}q} = (1, 1)\)

  1. 関連度（内積）：\(\vec{\vphantom{b}q} \cdot \vec{\vphantom{b}k}_{名前} = 1{+}1 = 2\)、同様に \(\vec{\vphantom{b}q} \cdot \vec{\vphantom{b}k}_{は} = 1\)、\(\vec{\vphantom{b}q} \cdot \vec{\vphantom{b}k}_{まだ} = 1\)
  2. 割合：合計4で割って \((0.5,\ 0.25,\ 0.25)\)
  3. 混ぜる：\(0.5 (1,0) + 0.25 (0,1) + 0.25 (1,1) = (0.75,\ 0.5)\)
  • 「まだ」の探しものと一番似た名札は「名前」→ 「名前」の情報が半分を占めた
  • 冒頭のクイズで目が「名前」に飛んだ、あの動きを数で再現した1往復

検算 — コードだと3行

import numpy as np

K = np.array([[1.0, 1.0], [1.0, 0.0], [0.0, 1.0]])   # 名札（「名前」「は」「まだ」）
V = np.array([[1.0, 0.0], [0.0, 1.0], [1.0, 1.0]])   # 持ってる情報
q = np.array([1.0, 1.0])                              # 「まだ」の探しもの

scores = K @ q                    # ① 関連度
weights = scores / scores.sum()   # ② 割合にする
print("重み:", weights)
print("混ぜた結果:", weights @ V)  # ③ 重み付き平均
重み: [0.5  0.25 0.25]
混ぜた結果: [0.75 0.5 ]
  • 手計算と一致。注意の中身は、内積と足し算だけ

クイズ

関連度が \((2, -1, -1)\) になったら？「合計で割る」方式で割合を作ってみると……

  • 合計は \(0\) — ゼロ割り崩壊。負の重み「\(-\infty\)%見る」も意味不明
  • 欲しい性質：常に正・合計1・大きいスコアほど強調
  • その専用部品はすでに使っている — 「学習で当てる」の softmax（\(e^s\) を取って合計で割る）
import numpy as np

def softmax(s):
    e = np.exp(s)
    return e / e.sum()

print(softmax(np.array([2.0, 1.0, 1.0])))     # さっきの例
print(softmax(np.array([2.0, -1.0, -1.0])))   # 負が混ざっても安全
[0.57611688 0.21194156 0.21194156]
[0.909443  0.0452785 0.0452785]
  • 以後、②の割合化は softmax で行う。さっきの例なら重み \((0.58, 0.21, 0.21)\) — 1位がより強調される

import numpy as np

K = np.array([[1.0, 1.0], [1.0, 0.0], [0.0, 1.0]])
V = np.array([[1.0, 0.0], [0.0, 1.0], [1.0, 1.0]])

def softmax(s):
    e = np.exp(s)
    return e / e.sum()

# 問題1: q=(0,2) → スコア (2,0,2) → 割合 (0.5,0,0.5) → (0.5)(1,0)+(0.5)(1,1) = (1.0, 0.5)
q = np.array([0.0, 2.0])
scores = K @ q
w = scores / scores.sum()
print("スコア:", scores, "| 割合:", w, "| 結果:", w @ V)

# 問題2: スコアが同じなら割合は (1/3, 1/3, 1/3) = 単純平均
same = np.array([5.0, 5.0, 5.0])
print("合計割り:", same / same.sum(), "| softmax:", softmax(same))
print("単純平均:", V.mean(axis=0), "=", (same / same.sum()) @ V)
スコア: [2. 0. 2.] | 割合: [0.5 0.  0.5] | 結果: [1.  0.5]
合計割り: [0.33333333 0.33333333 0.33333333] | softmax: [0.33333333 0.33333333 0.33333333]
単純平均: [0.66666667 0.66666667] = [0.66666667 0.66666667]
  • 問題2：softmax でもスコアが同じなら均等割り。「特に見るところがない」とき、注意は自然に平均へ退化する
