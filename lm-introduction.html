ChatGPT は何をしている機械か

質問

ChatGPT の中身がやっている仕事を、一言で言うと？ 「考えている」「検索している」「会話している」……？

  • 答え：次に来る言葉を予測している。それを繰り返しているだけ
  • この「次を当てる機械」を言語モデル（language model）と呼ぶ
  • 大規模にしたものが LLM（Large Language Model）— ChatGPT の本体

前コースのゴールを30秒で

  • 前コースの最終回に作ったのは「手書き数字を読む機械」— 種類でいうと分類器（classifier）
  • 入力は画像（28×28個の数値）。出力は 0〜9 の「棒グラフ」10本
    • 棒の高さ＝「その数字だと思う度合い」。全部足すと1 — この形を確率分布（probability distribution）と呼ぶ
  • 「これを入れたらこの棒が高くなるように」と、中の数値を学習で調整した

  • 採点係は交差エントロピー（cross-entropy）という損失 — ひとまず「正解に低い確率を付けるほど重くなる罰点」とだけ。中身は「学習で当てる」の回でもう一度開ける

ノート

本当に新しい概念は2つだけ：埋め込み（ことばを数にする）と注意（どこを見るか）。 それ以外は全部、知っている部品の組み替えで済む。

体験：君も言語モデル

ペアで交互に「次の1文字」を予想する。出題者は答えだけ知っている。

  • 第1問　「こんにち（　）」
  • 第2問　「吾輩は猫であ（　）」
  • 第3問　「今日の晩ご飯は（　）」
  • 第1問・第2問はほぼ全員正解。第3問は原理的に当てられない — この差はどこから来る？

当てやすさには濃淡がある

  • 第1問「こんにち（　）」：候補が事実上1つ — ほぼ確信
  • 第3問「今日の晩ご飯は（　）」：カレーも寿司も鍋もあり — お手上げの総当たり
  • つまり「次の1文字」には当てやすさの濃淡がある — これを数で表したものが確率分布
    • 確信 → 1本の棒がそびえる尖った分布
    • お手上げ → 低い棒がずらりと並ぶ平らな分布
  • 人間は文脈からこの分布を頭の中で作っている。同じことを機械にやらせたい

「予想」を数に置き換える

質問

『吾輩は猫である』全文（約32万字）で、「吾輩」の次に来た文字を数える。1位はどの文字？　2位は？

  • 「は」39%、「の」28%…… — 数えただけで「予想」が数になった
  • 言語モデルの中身はこの棒グラフの親玉 — どんな文脈にも棒グラフを返す機械

尖った分布と、平らな分布

  • 体験ゲームの「確信」と「お手上げ」も、数えれば形になる。「であ」の次と「、」の次：
  • 「であ」の次は「る」が 84.5%、候補は全部で12種類 — 第1問（こんにち）の世界
  • 「、」の次は1位の「そ」でも 6.3%、候補は1,044種類 — 第3問（晩ご飯）の世界
  • 予測のしやすさ＝分布の形。言語モデルの実力は、この形をどれだけ本物の続きに近づけられるか

1文字ずつなら、文章も書ける

  • 予測した1文字を文章の尻に足して、また次を予測する — この繰り返し

  • 自己回帰（autoregressive）と呼ぶ。ChatGPT が1語ずつ「打っている」ように見えるのは、本当に1語ずつ作っているから
  • 「当てる」ができれば「書ける」— だからこの講義は「次の1文字を当てる」だけを磨き続ける

生成を1歩ずつほどく

  • ぐるぐる回る絵を、まっすぐ伸ばして3歩ぶん：

  • 毎歩やることは同じ：いまの文脈を入れる → 棒グラフをもらう → 1本引く → 尻に足す
  • 機械は1台きり。伸びていくのは文脈のほう
  • 「引く」は抽選 — 同じ書き出しでも、実行のたびに違う文章になりうる。ChatGPT の答えが毎回少し違う理由も、ここ（ツマミの調べ方は「生成を操る」の回で）

この講義の道のり

  • 架空の地名メーカーを育てる：数えるだけのモデルから始めて、学習・埋め込み・文脈の窓へ
  • 注意（Attention）を開ける：「どこを見るか」を学習する仕組みを手計算からコードまで
  • GPT を組んで火を入れる：部品を束ねて『吾輩は猫である』32万字で訓練する
  • 推し文豪ボット：最終回、好きな作家で自分のGPTを育てる — そして文豪テストの答え合わせ

どの回も「小さく作って動かして、1個だけ賢くする」の繰り返し。 動かないものを3回我慢する回は、ひとつもない。

演習：数えるだけの予測器

『吾輩は猫である』で「猫」の次に来る文字を数え、確率の高い順に5つ表示せよ。

  1. neko.txt をダウンロードして、作業フォルダの data/ に置く
  2. open("data/neko.txt", encoding="utf-8").read() で全文を読み込み
  3. find で「猫」の位置を順に探し、その次の1文字を辞書で数える（collections.Counter 可）
  4. 回数の多い順に5件、「文字：回数」で表示
解答例を見る 
from collections import Counter

text = open("data/neko.txt", encoding="utf-8").read()
nxt = Counter()
i = text.find("猫")
while i != -1:
    if i + 1 < len(text):
        nxt[text[i + 1]] += 1
    i = text.find("猫", i + 1)

for c, n in nxt.most_common(5):
    print(c, n)   # 「の」「で」「と」…… — 「猫の」「猫である」が見えてくる

まとめ

  • 言語モデル＝次の1文字を当てる分類器。MNIST と同じ形、同じ損失
  • 予想の濃淡は確率分布の形で表せる — 確信は尖り、お手上げは平ら。数えるだけでも分布は作れる（今日の棒グラフ）
  • 1文字当てて尻に足す（自己回帰）を繰り返せば、文章が書ける
  • 新しい概念は埋め込みと注意の2つだけ — あとは持っている道具の組み替え

現在の設計図　文脈 → 語彙全体の確率 → 次の1文字 → 文脈へ戻す

問題1：尖りと平らを実測する

『吾輩は猫である』で、「であ」の次に来る文字と「、」の次に来る文字をそれぞれ数え、候補の種類数と1位の文字とその確率を表示せよ。

  1. neko.txt を data/ に置く（演習と同じ）
  2. 演習のコードの「猫」を「であ」「、」に替えて数える（次の文字の位置は i + len(文脈)）
  3. 種類数は len(nxt)、1位は nxt.most_common(1) で取り、「種類数」「1位の文字：確率」を表示
  4. どちらが「こんにち」型で、どちらが「晩ご飯」型か、本編の図と見比べる

解答例

解答例を見る 
from collections import Counter

text = open("data/neko.txt", encoding="utf-8").read()

for ctx in ["であ", "、"]:
    nxt = Counter()
    i = text.find(ctx)
    while i != -1:
        j = i + len(ctx)
        if j < len(text):
            nxt[text[j]] += 1
        i = text.find(ctx, i + 1)
    total = sum(nxt.values())
    c, n = nxt.most_common(1)[0]
    print(f"「{ctx}」の次: {len(nxt)}種類 | 1位「{c}」 {n / total:.1%}")
「であ」の次: 12種類 | 1位「る」 84.5%
「、」の次: 1044種類 | 1位「そ」 6.3%
