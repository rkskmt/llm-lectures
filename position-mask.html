質問

自己注意に「ねこがねず」と「こねがねず」（前4文字を並べ替え、最後は同じ）を入れる。 最後の文字の出力は変わるか？

事件1：順番を替えても何も変わらない

import torch
import torch.nn as nn
import torch.nn.functional as F

class SelfAttention(nn.Module):                     # 前回のクラスそのまま
    def __init__(self, n_embd, head_size):
        super().__init__()
        self.query = nn.Linear(n_embd, head_size, bias=False)
        self.key   = nn.Linear(n_embd, head_size, bias=False)
        self.value = nn.Linear(n_embd, head_size, bias=False)

    def forward(self, x):
        q, k, v = self.query(x), self.key(x), self.value(x)
        w = F.softmax(q @ k.T / k.shape[-1] ** 0.5, dim=-1)
        return w @ v

torch.manual_seed(0)
sa = SelfAttention(n_embd=8, head_size=4)
emb = nn.Embedding(10, 8)

tokens   = torch.tensor([3, 1, 4, 1, 5])
shuffled = torch.tensor([1, 4, 1, 3, 5])            # 前4文字を並べ替え
diff = (sa(emb(tokens))[-1] - sa(emb(shuffled))[-1]).abs().max()
print(f"最後の文字の出力の差: {diff:.1e}")
最後の文字の出力の差: 1.5e-08
  • 差はほぼ0（丸め誤差だけ）。「がねこ」と「ねこが」の区別が付いていない

犯人は足し算 — 混ぜ物に順番はない

  • 注意の出力は \(v\) の重み付き平均 — つまり足し算。足す順番を替えても合計は変わらない
  • 重みを決めるスコア \(q \cdot k\) も1対1の内積で、「何番目か」はどこにも入っていない
  • 自己注意は文を文字の集合（袋）として見ている — 「ねこが」も「がねこ」も同じ袋。日本語で順序が消えたら大惨事

解決1：位置にも埋め込みを配る

  • 「何文字目か」という情報も、文字と同じように埋め込みベクトルにしてしまう
  • 文字のベクトルに足してから自己注意に渡す

pos = nn.Embedding(16, 8)                 # 位置番号 0〜15 の埋め込み表

def with_pos(t):
    return emb(t) + pos(torch.arange(len(t)))

diff = (sa(with_pos(tokens))[-1] - sa(with_pos(shuffled))[-1]).abs().max()
print(f"位置を足した後の差: {diff:.4f}")
位置を足した後の差: 0.1176
  • 差が出た — 同じ「ね」でも1文字目のねと4文字目のねは別のベクトルになる
  • この位置の表（pos）が位置埋め込み（positional embedding）。表も学習される — 「位置の使い方」まで勾配降下まかせ

学習された「位置の表」を覗く

  • では、訓練を終えた表には何が入っているのか。完成品（最終回のモデル）から64本を取り出して比べる
  • 赤いのは対角線（自分×自分）だけ — どの位置とも似ていない、ほぼ直交の「住所札」64本
  • 隣どうしすら似せていない（隣接位置の平均類似度 0.08）。このモデルに必要だったのは「近さ」ではなく区別だった

事件2：訓練中の視線は未来を見ている

  • 言語モデルの訓練は「各位置で次の文字を当てる」だった
  • ところが前回作った視線の表（誰が誰をどれだけ見るかの \(T \times T\)）は全部埋まっている — 3文字目の行が5文字目も見ている

質問

「次の文字を当てよ」というテスト中に、答えの文字そのものが見えていたら何が起きる？ 訓練の成績と、生成（本番）の成績、それぞれどうなる？

  • 訓練：正解を丸写しできるのでほぼ満点
  • 本番の生成：未来の文字はまだ存在しないので、丸写し戦略は白紙 — 大崩壊
  • 「あやしい満点」、三たび。今回は過学習ではなくカンニングが原因

解決2：因果マスク — 未来の視線を封じる

  • 視線の表の「未来」のマス（右上半分）を、softmax の前に \(-\infty\) にする — これが因果マスク（causal mask）
import torch
import torch.nn.functional as F

scores = torch.arange(1.0, 17.0).reshape(4, 4)     # 視線スコアの例
tril = torch.tril(torch.ones(4, 4))                # 左下三角だけ1
masked = scores.masked_fill(tril == 0, float("-inf"))
print(masked)
print(F.softmax(masked, dim=-1).round(decimals=3))
tensor([[ 1., -inf, -inf, -inf],
        [ 5.,  6., -inf, -inf],
        [ 9., 10., 11., -inf],
        [13., 14., 15., 16.]])
tensor([[1.0000, 0.0000, 0.0000, 0.0000],
        [0.2690, 0.7310, 0.0000, 0.0000],
        [0.0900, 0.2450, 0.6650, 0.0000],
        [0.0320, 0.0870, 0.2370, 0.6440]])
  • softmax を通すと \(e^{-\infty} = 0\) — 未来の重みがきっかり0%になる
  • 1文字目は自分しか見えない、2文字目は2人まで…… 段々畑の視線になる
  • 前回エクスプローラで見た「視線の表の右上半分が空」の正体がこれ — 訓練済みの本物には最初からこのマスクが入っていた

なぜ 0 ではなく −∞ を入れる？

スコアに 0 を入れても \(e^0 = 1\) で票が入ってしまう（3人同点なら33%ずつ）。 「見えない」を作れるのは \(-\infty\) だけ。

注意ヘッド、完成

  • 位置は入口で足すので、注意側の変更はマスクの2行だけ。この形をヘッド（head）と呼ぶ

import torch
import torch.nn as nn
import torch.nn.functional as F

class Head(nn.Module):
    """マスク付き自己注意（言語モデル用の完成形）"""

    def __init__(self, n_embd, head_size, block_size):
        super().__init__()
        self.query = nn.Linear(n_embd, head_size, bias=False)
        self.key   = nn.Linear(n_embd, head_size, bias=False)
        self.value = nn.Linear(n_embd, head_size, bias=False)
        self.register_buffer("tril", torch.tril(torch.ones(block_size, block_size)))

    def forward(self, x):                            # x: (T, n_embd)
        T = x.shape[0]
        q, k, v = self.query(x), self.key(x), self.value(x)
        w = q @ k.T / k.shape[-1] ** 0.5
        w = w.masked_fill(self.tril[:T, :T] == 0, float("-inf"))   # 未来は見ない
        w = F.softmax(w, dim=-1)
        return w @ v

torch.manual_seed(0)
head = Head(n_embd=8, head_size=4, block_size=16)
print(head(torch.randn(5, 8)).shape)
torch.Size([5, 4])
  • block_size は「一度に見られる最大文字数」。register_buffer は「学習しない定数」の置き場

マスク前後の視線

  • 右：どの行も自分から左だけで合計100%。生成のときと同じ条件で訓練できる

Tweak 事件をもう一度起こす

  • 本編のコードを組み合わせて実験（Head と with_pos を1つのファイルにまとめて実行）
変えること 何が起きるか
masked_fill の行をコメントアウト 視線の表の右上が復活する（ヒートマップで確認）
float("-inf") → 0.0 「見えない」が「同点の1票」に化ける。1行目の重みで確認
pos(...) を足すのをやめる シャッフル実験の差がまたほぼ0に戻る

ここで観察

  • 3つとも「壊す実験」。部品の役割は、外したときに一番よく分かる
  • マスクを外した瞬間、訓練成績だけが不当に良くなる — 数字が良くなる変更が改善とは限らない

まとめ

  • 事件1：自己注意は順序を知らない（足し算だから）→ 位置埋め込みを文字の埋め込みに足す
  • 事件2：訓練中に未来が見える（カンニング）→ 因果マスクで右上を \(-\infty\) に
  • \(e^{-\infty} = 0\) が「見えない」を作る。0 ではダメ（票が入る）
  • 言語モデル用の注意ヘッドが完成 — Head クラスはこの先そのまま使う

現在の設計図　文字＋位置 → 因果マスクつき自己注意 → 文脈つきベクトル

import torch
import torch.nn.functional as F

# 問題1
print(F.softmax(torch.tensor([float("-inf"), 0.0, 0.0]), dim=0))   # (0, 0.5, 0.5)
print(F.softmax(torch.tensor([0.0, 0.0, 0.0]), dim=0))             # (1/3, 1/3, 1/3)
# 0 は「同点の候補」として票をもらえてしまう。視線を消せるのは -inf だけ

head17 = Head(n_embd=8, head_size=4, block_size=16)
